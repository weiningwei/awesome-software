## 通用下载器

- [Motrix](https://github.com/agalwood/Motrix) - 跨平台下载器，支持 HTTP/FTP/BT/磁力链。 `跨平台` `MIT` ![GitHub Release Date](https://img.shields.io/github/release-date/agalwood/Motrix?display_date=published_at&style=flat)
- [gopeed](https://github.com/GopeedLab/gopeed) - 跨平台下载器，支持 HTTP/BT/磁力链。 `跨平台` `GPL-3.0` ![GitHub Release Date](https://img.shields.io/github/release-date/GopeedLab/gopeed?display_date=published_at&style=flat)
- [ab-download-manager](https://github.com/amir1376/ab-download-manager) - 多线程下载管理器。 `Windows` `Apache-2.0` ![GitHub Release Date](https://img.shields.io/github/release-date/amir1376/ab-download-manager?display_date=published_at&style=flat)
- [Varia](https://github.com/giantpinkrobots/varia) - aria2 与 yt-dlp 的图形前端下载管理器，支持普通文件、BT 种子与视频/音频流下载。 `跨平台` `MPL-2.0` ![GitHub Release Date](https://img.shields.io/github/release-date/giantpinkrobots/varia?display_date=published_at&style=flat)
- [Rayburst](https://github.com/AnInsomniacy/rayburst) - 全功能下载管理器。 `跨平台` `MIT` ![GitHub Release Date](https://img.shields.io/github/release-date/AnInsomniacy/rayburst?display_date=published_at&style=flat)
- [FluxDown](https://github.com/zerx-lab/FluxDown) - Rust 驱动的多协议下载管理器，支持 HTTP/FTP/BitTorrent/磁力链/HLS/DASH。 `跨平台` `AGPL-3.0` ![GitHub Release Date](https://img.shields.io/github/release-date/zerx-lab/FluxDown?display_date=published_at&style=flat)
- [Ghost-Downloader-3](https://github.com/XiaoYouChR/Ghost-Downloader-3) - 全协议下载器，支持 HTTP/BT/FTP/M3U8/DASH/eD2k 及 YouTube/B站/GitHub/HF 解析。 `跨平台` `GPL-3.0` ![GitHub Release Date](https://img.shields.io/github/release-date/XiaoYouChR/Ghost-Downloader-3?display_date=published_at&style=flat)
- [Hydra](https://github.com/ja7ad/hydra) - 跨平台下载管理器，通过多连接与多镜像分片加速下载，支持 HTTP/FTP/Metalink 并提供命令行、TUI 与桌面 GUI。 `跨平台` `GPL-3.0` ![GitHub Release Date](https://img.shields.io/github/release-date/ja7ad/hydra?display_date=published_at&style=flat)
- [Plexo](https://github.com/anmolkapil/plexo) - 通过合并多个网络连接并行加速下载的下载器。 `跨平台` `MIT`
